Alone in the Dusk - glTF download

Every .glb in single_models/ now carries its own colour map inside the file, so a model
imports textured in Blender, Unity, Unreal, Godot or anything else that opens glTF. There
is nothing to hook up by hand.

AloneInTheDusk_all_models_textured.glb holds the kit models in one file, also textured.

Textures/ carries the full resolution maps: the shared atlas for the kit models, plus the
maps used by the bridges, rocks, roads and terrain. The copies inside the .glb files are
reduced to the size the pack's own look samples them at, which is what the PSX picture
needs. Swap in the full resolution map from this folder if you want a sharper surface.
